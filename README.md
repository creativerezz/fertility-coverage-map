# Fertility Coverage Map

Interactive US map for egg freezing / fertility preservation insurance coverage.

## Stack
- Next.js 16.4+
- TypeScript
- Tailwind CSS v4
- shadcn-style components
- Motion

## Coverage data
Expanded state data for CA, IL, NY, MA, CO, TX, FL, GA, PA.

## Run
```bash
npm install
npm run dev
```

Data is informational only — always verify with your specific plan.
